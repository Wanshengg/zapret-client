# Zapret Client

Настольный Windows-клиент для [Flowseal zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Позволяет подключать и отключать zapret, выбирать стратегию, просматривать журнал проверок и обновлять конфиги через графический интерфейс.

## Возможности

- подключение и отключение zapret одной кнопкой;
- автоматический и ручной выбор стратегии;
- полная проверка стратегий с HTTP/TLS-метриками, ICMP ping и DPI TCP 16–20 КБ;
- автоматический выбор лучшей стратегии по доступности, DPI и пингу;
- журнал результатов проверок с подробными сетевыми метриками;
- автоматическое подключение при запуске, начиная с последней рабочей стратегии;
- автоматическое обновление конфигов zapret;
- проверка новых релизов самого клиента с загрузкой установщика;
- запуск вместе с Windows и автоподключение после перезагрузки;
- сворачивание в системный трей с управлением подключением через меню значка;
- светлая, тёмная и системная темы с сохранением выбора.

## Скачать и установить

1. Откройте [последний релиз](https://github.com/Wanshengg/zapret-client/releases/latest).
2. Скачайте `Zapret Client Setup 0.1.0.exe`.
3. Запустите установщик от имени администратора и следуйте инструкциям.

Требуется 64-разрядная Windows 10 или Windows 11. Для работы zapret нужны права администратора.

Установщик не подписан кодовым сертификатом, поэтому Windows SmartScreen может показать предупреждение.

## Как обновить

### Саму программу

Клиент проверяет новые релизы после запуска и каждые 6 часов. Если доступна новая версия, откройте **Настройки → Обновление программы → Скачать обновление**, затем запустите установщик поверх установленной версии. Настройки и скачанные конфиги сохраняются.

### Конфиги zapret

Откройте **Настройки → Обновление конфигов → Проверить сейчас**. Если включено автоматическое обновление, клиент также проверяет новые конфиги после запуска и каждые 6 часов.

Обновление конфигов и обновление самого клиента — отдельные операции.

## Автозапуск и трей

По умолчанию после запуска клиент автоматически проверяет стратегии и подключается, начиная с последней рабочей. Для подключения после перезагрузки Windows включите **Настройки → Запускать клиент вместе с Windows**.

Кнопки сворачивания и закрытия скрывают окно в системный трей, не останавливая zapret. Через меню значка можно открыть окно, подключиться, отключиться или полностью выйти из клиента.

## Запуск из исходников

Требуется Node.js 24 или новее.

```bash
npm install
npm run dev:electron
```

Проверки и сборка:

```bash
npm test
npm run build
npm run dist
```

Готовый установщик появится в каталоге `release`.

## Исходный проект

Конфиги и исполняемые компоненты zapret загружаются из официальных релизов [Flowseal zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Этот репозиторий содержит только графический клиент.
